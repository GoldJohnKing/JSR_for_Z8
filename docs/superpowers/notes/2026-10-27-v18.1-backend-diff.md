# V18.1 引擎与已集成 2.3.27 的逐条目差异实证（2026-10-27）

背景：上游发布 JSR V18.1（Sharp 独立包，`reference/JSR_V18.1/JSR_V18.1_Sharp`），评估七帧（K7/Stormer7）模型与算法是否与已集成的 Jiangtherapee Bridge 2.3.27 有差异，随后升级载荷源。方法：以与 `tools/pack-payload/EnginePreextractor` 相同的解析规则解包两版 `resources/jsr_backend.exe` 的 PyInstaller CArchive（cookie/TOC/逐条目 zlib），并解开 PYZ 内层，逐条目比对 SHA-256；关键 code object 用手写 3.10 marshal 解析器反汇编。

## 结论

- **神经网络模型与融合管线逐字节相同**；**对齐算法被 V18.1 运行期猴补丁整体替换**（CPU 曝光掩码四次项场，无 SPyNet）；argv/协议契约不变；dark 模块差异仅为 S5II LUT 输入分支（不触达 argv 标量路径）。

## 证据

### 相同（SHA-256 逐条目一致）

- K7 融合权重 `wgpu/assets_v15_2/backend_{32,64,96,128,192,256}.npz`（各 12,362,918 B）+ JSON 配置 + `spynet.npz` + `validation/v15_2/*.npz` + `fixtures/*`。
- `v15_2` 管线模块全部：pipeline/registration/physical/deghost/scene_*/frame_order/highlights/roi/ops/tuning/memory/runtime/gui/industrial_tiff/… 与 `alignment.pyc`（SPyNet 路径，V18.1 中被补丁旁路）。
- `jsr_v15_2.pyc`（CLI 入口，argv 契约所在）与内嵌主逻辑 marshal blob（17,412 B，两版 sha256 相同）。
- `product_v152/` 全部 21 条（legacy 输出链 v124_dng/v82_lca/lossless repack、ptc_index.csv、srhq_joraw2.dll 等）。
- `jsr_options.json`（两版 sha256 相同，与 manifest options_sha256 一致）。
- CArchive 层 1380 条相同；PYZ 层 1440 条相同。

### 差异

1. **对齐替换（核心）**：V18.1 新增外层引导器 `backend.py`（'s' 条目，272 B 字节码）：
   - 启动即 `from v15_2.masked_alignment import install; install()` → 无条件 `pipeline.align = <新 align>`、`pipeline.Geometry = MaskedGeometry`（`geometry.Geometry` 子类，AnalyticFields 连续原生坐标 + 保留 deghost 网格视图）；
   - 新增独立 CLI 模式 `--masked-align-export <input> <output>`（`Runtime(6e9)` 预算）；
   - 之后 `marshal.loads(旧 backend_batch_entry blob)` 并 exec —— **旧主逻辑逐字节原样内嵌执行**。
   - `pipeline.run` 内 `LOAD_GLOBAL align`（偏移 480）实证补丁对 K7 主流程生效。
   - 2.3.27 原路径：GPU SPyNet（Proxy 上传 → registration 全局 H → SPyNet flows → WGPU homography_warp/predict）。V18.1 新路径：`registration.register` 全局 H + 逐对 `masked_local.align_pair`（"sealed V9.8 ECC fitter for V12.1"，CPU：cv2 + ThreadPoolExecutor），参数 `(192,128,6)`=BS192/stride128/search6、max_degree 4/cap −4，与 manifest `stormer_alignment_parameters` 声明一致，`stormer_spynet_used: false`。
   - 新模块 `v15_2.masked_{alignment,fit,geometry_cpu,local}` 同时存在于 PYZ（优化编译副本）与 CArchive 'x' 数据条目（带 docstring 副本，合计 34,228 B）。**落盘语义（2026-10-27 E2E 排障实证）**：引导器把 `<MEIPASS>/wgpu` 插入 sys.path 首位后，`v15_2` 包及子模块从磁盘树导入（磁盘包遮蔽 PYZ）；'x' 条目属于引导器自解压的落盘集（与 'b' 同列），只解 'b' 的预解包树缺位 x 文件即启动期 `ModuleNotFoundError: No module named 'v15_2.masked_alignment'`（backend.py line 5）——修复=EnginePreextractor 落盘集扩为 b+x（x 体在薄拷贝中保留不清零，清零实证仅覆盖 b）。
2. **dark 模块**：`v15_2.dark.apply_dark_to_manifest` 1564→1652 B，唯一功能差异 = 入口新增第一分支 `.json` → `from measured_dark_lut import report_and_metadata`（schema `JSR_MEASURED_DARK_PROFILE_V1`：black_dn/white_dn/offset_dn/haar_variance_dn2/cfa_index/exposure_s/camera_model）——S5II 实测标量 LUT 输入；原 `.npy`/RAW(decode_raw) 分支逐指令未动（剥偏移归一化反汇编 diff 证实其余同构，仅常量/变量编号平移+局部改名）。谱系：该改动 2.3.27→17.2.1 期间发生（17.2.1 与 18.1 的 dark.pyc 逐字节相同），早于 18.1。
3. **构建层（非算法）**：V18.1 exe 为"净化重打包"（`resources/release_sanitize_report.json` 全程留痕：cv2/wgpu/imgui 源码条目 migrate_pyc、numpy.testing/`wgpu.__pyinstaller`/PYI 桩移除、PE 校验和重算、CArchive 重列化、保留条目压缩字节原样拷贝）——解释其 manifest `backend_sha256`(4d2566c4…) 与实际 exe(398b927d…) 不符。新增 `jsr_traditional_3x_backend.exe`（131 MB，30–2000 帧 Sharp 传统 3× 路径，本项目排除）；k14/fastK14 权重哈希与 2.3.27 相同（exe 本体重打包）。
4. **manifest 字段**：V18.1 增 S5II 系列、`stormer_alignment: global_H_highlight_masked_quartic`、`stormer_spynet_used: false`、`stormer_alignment_parameters: existing exposure-masked V12.1 local fitter; unchanged BS192/stride128/search6/max_degree4/cap4`、`jsr_standalone_version: 17.3.1`。注意 "existing/unchanged" 指相对 JSR 独立版谱系（17.3.1），**不**相对 2.3.27——2.3.27 的 K7 对齐是 SPyNet。

## 升级落点（本项目）

- `build.bat`：源发现扩为两级——`reference\JSR_V*\JSR_V*_Sharp`（嵌套，优先）→ `reference\Jiangtherapee-Bridge-*`（平铺回退）；JSR 版本号恒高于 2.3.x Bridge，存在即胜出。
- `PayloadPacker`：版本正则 `^(?:Jiangtherapee-Bridge-|JSR_V)(\d+(?:\.\d+){1,3})`；排除清单新增 `resources/jsr_traditional_3x_backend.exe`（131 MB，30–2000 帧 Sharp 传统 3× 路径，七帧管线从不 spawn）。
- `EnginePreextractor`：落盘集 'b'→'b'+'x'（见上）；微型 CArchive 测试同步加 x 条目回归钉。
- UI 右上角版本行改标「JSR v…」（原「Jiangtherapee Bridge v…」，产品线已更名）。
- argv 模板、stdout 裸行协议、输出命名（`_V15_3_5_K7_`）全部不变（CLI/管线模块逐字节相同）；七帧输出像素与 2.3.27 不同属预期（对齐算法不同）。
- 验收：全量单测 312/312 绿；`--selftest` 绿（载荷 1,413 文件全 SHA 校验+LibRaw 冒烟）；E2E 四格式 Theory+中文路径 6/6 绿（~36.6 min，masked CPU 对齐较原 GPU SPyNet 路径慢，约 9 min/全幅组）。
